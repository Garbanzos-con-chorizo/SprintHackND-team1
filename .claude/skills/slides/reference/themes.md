# Themes (in `docs/pitch/tools/deckgen.py`, `THEMES`)

Each is one dark, one light, ONE anchor color, one warning color. Pick by previewing the real first slide in all three.

| Theme | Feel | Ink / paper / anchor / warn | Type |
|---|---|---|---|
| `signal` (default since deep dive; see github-skills-deep-dive.md) | Navy + paper + portal blue, Georgia / Segoe UI / Consolas, no web fonts | #0B2545 / #F7F5F0 / #0054A4 | system fonts |
| `plain` (superseded) | Portal colors, system fonts, works offline | #231F20 / #FFFFFF / #0054A4 / #B25000 | Georgia + Segoe UI / Helvetica / Arial |
| `swiss` (needs Google Fonts) | Goodwill portal look: product and slides read as one | #231F20 / #FFFFFF / #0054A4 / #B25000 | IBM Plex Sans |
| `keynote` (bold) | Apple keynote: dark stage, huge numbers | #F5F5F7 on #111113 / #2997FF / #FF9F0A | DM Sans |
| `ledger` (wildcard) | Editorial finance paper: serif headlines, ruled tables | #1B1B1B / #FAF8F3 / #0B5D3B / #A4361B | Source Serif 4 + IBM Plex Sans |

Avoid: Inter/Roboto/Arial as display face, purple gradients, centered everything, identical card grids, decorative shadows.
