# docs/pitch/

Everything for the presentation and the recorded demo.

| Path | Why |
|---|---|
| `presentation-guide.md` | The plan for the talk: what we hand in, rubric, storyboard, disclosures |
| `demo-script-pulse.md`, `demo-script-close.md` | What to run, say and point at, per part of the take |
| `engine-pitch.md`, `kpi-catalog.md` | Rubric line by line for phase 1; the KPI list |
| `deck/` | `content.json`: the deck's text, the only file you edit to change slides |
| `specs/` | Spec-driven development folders (`NNN-slug/`: spec, plan, audits) |
| `tools/` | Importable modules (deck renderer, linter) + tests |
| `scripts/` | Commands: `build_deck.py`, `new_spec.py`, `audit_phase.py` |
| `archive/` | Superseded proposals, kept for the record |
